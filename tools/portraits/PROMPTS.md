# Commander portrait prompts

The game currently uses 3D-rendered busts. If you would rather use AI-generated paintings, generate the 30 images below, then run `python3 tools/portraits/install.py <folder>` (see README in this folder). The file names must match exactly (for example `sikaman_1.png`).

**Common style (paste after every prompt):**

> Painted portrait, head and shoulders, three-quarter view, looking slightly past the viewer, dignified commander, rich oil-painting texture, dramatic warm side lighting, historical realism, detailed face, dark vignette background with a subtle civilisation colour, square 1:1, no text, no watermark, no frame.

Tips: keep the same style line for all 30 so they feel like one set; use `--ar 1:1` in Midjourney or the square option elsewhere; 1024x1024 is plenty.
